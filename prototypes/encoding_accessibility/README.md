# Encoding, mutation accessibility and a paid copy channel

This is a new representation/accounting experiment using the immutable #325
result artifact. It runs no old controller, environment, seed bank, native VM or
population. Original reward8, scores, operations and failed hypotheses remain
unchanged. Earlier validation data is reused exploratory evidence, not a new
unseen-condition test.

Two encodings are fixed before analysis:

* Moore8: two blank-action bits and six next-state bits. Four ignored feedback
  output bits from the old12-bit table are fixed0.
* Event6: two blank-action bits and four feedback next-state bits. Blank input
  additionally holds state automatically.

These are designer-supplied codec/hardware priors. They do not encode a successful
learning update, but event-gated persistence is task-favouring and must not be
called evolved compression. Every64/256 genotype maps injectively into the
retained complete4096 records; each mutation maps to one original free bit.
All192/1024 undirected mutation edges and failed/no-benefit endpoints remain.

At the unchanged reward, each phenotype is quoted at6/8/12 code bits, with the
same state, sensor, transition and changed-state-write prices. Fixed controls
retain their cheap specialized representation. The strong win-stay/lose-shift
control receives exactly the candidate's code quote. This separates a smaller
representation from new behavior; ties with the strong control are not progress
beyond conventional methods. Decoder and within-life CPU cost have not been
measured for these encodings, so accounting gains are not fitness measurements.

The mutation graph starts blind genotype0, explores ascending bit positions and
permits nondecreasing development net. The lowest-ID reachable endpoint beating
fixed is recorded with every intermediate's development and reused-validation
score. No path is claimed to be a real lineage: aggregate scores can hide early
bankruptcy, and a founder can lose resources on different schedules.

A separate pure copy primitive actually copies each serialized bit, charging
one modeled CPU unit and one formation unit per bit. It charges one blank-state
unit, one division CPU unit and transfers8 startup units only when the complete
bill is affordable. Partial nurseries and all energy/material balances are
retained. Test all6/8-bit parents, faithful copying and every single-bit location
at budgets0,required-1,required. The12-bit reference uses two arbitrary parents
at the same three boundary budgets. The complete bills22/26/34 are conditional
on this disclosed toy channel, not native Ora reproduction prices. No parent
life, actual organism birth/death, food capture or descendant success is run.

The unchanged byte-pinned Windows runner from #325 supplies the same containment
and limitations. This folder's `census.py` performs projection/copy fixtures only.
Run unit checks with:

```
python -B -m unittest discover -s prototypes/encoding_accessibility -p test_projection.py -v
```

One prospectively frozen execution uses a NEW output directory:

```
python -B prototypes/encoding_accessibility/bounded_runner.py --directory NEW_DIRECTORY
```

Any evolutionary population is a separate admission. Before execution it needs
an exact finite protocol/source, blind founders, true within-life debit ordering,
endowment/material/energy conservation, failed copies/deaths, actual decoder
cost, mutation probabilities, all-member denominators, matched conventional and
no-mutation/erasure/inheritance controls, fresh independent contexts, stopping
rules, bounded original-owner custody and independent review. A favorable
projection or copied fixture does not pass those gates. No reward retuning,
supplied winning founder or mutation/reproduction dynamics is authorized here.
