# Experience affordance: isolated finite controller census

This is a new, explicitly altered **exploratory software environment**, not a new
Ora scientific World, admitted population, EKA replay, or replacement VM. No
historical seed, genome, bank, signed memory or running assistant is imported.

The question is whether a very small heritable controller class can use its own
action feedback after a delay, repay explicitly stated toy costs, and have a
nondecreasing single-bit path from a disclosed blind table. Every one of the
4096 twelve-bit tables is included, including failures. There are 24576
undirected single-bit edges. The supplied table interpreter contains no learning
update; next-state and action bits are the entire variable program. Exhaustive
enumeration is a researcher-supplied search, not naturally observed evolution.

Each two-state controller receives blank input2 for an attempt. Its own action p
produces success f=[p==target], supplied as input0/1. The hidden target stays fixed
through two subsequent scored probes and changes only at the next block.
Feedback is absent at probes: their input is blank2, as at attempts and delays.
Observation type is an explicit supplied cue; target, block index, delay counter,
elapsed time and attempted-port decoder are not available to the controller.
Outputs use the old state/input, then the transition updates state. State starts
zero per sequence and persists across blocks. All binary target sequences of
length3 with delays0/1 are development; all length4 with delays2/3 are validation.
These are finite overlapping task families, not unseen arbitrary environments.

True and identity-sham must match exactly. Feedback-clamped-to0, complemented
feedback and state-reset-before-EACH-probe are separate lesions. Every arm earns
feedback from its own attempted action. Clamp0 is not absent feedback, and reset
can disrupt clock as well as stored content. External interventions are counted
separately; they do not receive natural costs or refunds. Costs include all
natural transitions, sensing, changed-state writes, one-bit state formation and
twelve-bit code formation once per sequence, plus a declared storage-cost sweep.
This is a priced ledger, not an energy-limited survival simulation. Host costs
are measured separately; no host-to-organism exchange rate is invented.

Controls include cheaper fixed0/1 which skip nondecision work, all eight
memoryless input maps, a supplied raw-success latch and a strong conventional
one-bit win-stay/lose-shift controller. The latter retains its attempted port and
flips on failure; its twelve-bit representation and costs match the table class.
It should solve this simple task perfectly. A table tying it is not a new
learning algorithm or superiority over conventional methods. Opportunity-based
selection versus fixed/memoryless/latch and comparisons against this strong
reference remain explicitly separate. No selected controller is inserted as an
organism founder: there is no population.

Selection minimizes the exact development reward break-even bound, then genotype
ID. The single-bit BFS starts blind table0 and permits only nondecreasing
development net at reward8/storage0; neighbor bits ascend0..11. The choice/path
and development-record hash are exclusively saved before any validation outcome
evaluation. Price sweeps reward1..16/storage0..4 are diagnostics, never retuning
or a scientific acceptance gate. No sampling p-values are warranted. A path is
not an observed viable lineage; formation/copy affordability is not an actual
birth, survival, death or inheritance measurement.

Run the six small semantic checks with:

```
python -B -m unittest discover -s prototypes/experience_affordance -p test_census.py -v
```

census after a waiting trusted bootstrap in one Job:256MiB committed memory,

```
python -B prototypes/experience_affordance/bounded_runner.py --directory NEW_OUTPUT_DIRECTORY
```

This has no reproduction, mutation supply, selection dynamics, competitors,
material conservation, lifespan or naturally evolved instruction routine. It
can locate a small affordable memory affordance and mutation topology, or rule
them out within this class/task/prices. It cannot establish native-VM parity,
paid reproductive fitness, heritable advantage or open-ended intelligence.
