# Ora recorded universe observer

Static, read-only public recording. No simulation worker, mutation endpoint or
live process feed is deployed. Playback selects existing historical states.

The published HEARTBEAT-04 template-reference was independently audited against
its archived source, revision 3bc1ca652c2dd31ec46a13061604ff56d2ecc6fb.
It contains 33 states, 32 events, 96 abstract atoms and 41 object birth records.
Coordinates are not recorded; the atlas is explicitly schematic.
The UI validates data identity, ordering, hashes and conservation before display.

This engineering continuity reference does not demonstrate self-maintenance,
reproduction, evolution, learning or intelligence. Its scientific source pilot
failed its admission screen; negative evidence is preserved.

Future autonomous operation needs a separate authenticated read-only feed or
reviewed snapshot publication pipeline. A browser must never control the worker.
This fixed release does not connect to or expose the laboratory filesystem.
