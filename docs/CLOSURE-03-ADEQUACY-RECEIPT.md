## What this establishes and what it cannot

The reference measures structural encounter frequency and matched-token
availability. It omits births, decay, material competition and ancestry by
externally freezing each pool. The full dynamics can create or destroy
recipes, so this is neither a universal bound nor a repair-success probability.
Uniform independent draws idealize the53-bit random grid and PRNG.

The target was fixed before new calibration genomes were drawn, unlike the
earlier observer-selected lexicographic motif. These synthetic snapshots were
damaged directly at genesis, with no burn-in. Therefore this is not an
explanation, reclassification or statistical test of NATURAL-01's null result.
The80% criterion is a planning throughput benchmark, not statistical power for
a causal restoration effect. Passing an authored case does not admit a dynamic
study or justify seeding favourable actors into a supposedly emergent organism.

## Decision and concrete next development gate

Decline further repair studies with this exact random-generator splice assay
for now. Preserve it as a null/control; do not tune the frozen populations,
increase their horizons, arrange favorable encounters or inspect reserved
seeds8000..8063. No new held-out confirmation is warranted.

Next prepare a separately frozen competing-substrate design and budget check.
Compare (1) a locally constructed resource-access interface with (2) a costly
environmental trace, each against its fixed-physics/table/reflex counterpart.
The comparison must specify natural opportunities and ledger costs before
evaluating persistence, repair, memory or inheritance. These are candidate
mechanisms, not a plan to combine modules until something appears alive.

Minimum acceptance conditions for that new design:
- Define common finite material/fuel accounts; construction and use both pay.
- Count natural opportunities, unavailable controls and all starting cases.
- Separate functional effects from geometry, transport and resource subsidies
  using cost-matched disabled/ghost mechanisms and externally flux-matched
  supply where relevant; report trajectory-total cost differences.
- For traces, distinguish endogenous production/readout from designer-supplied
  visited-state; include false/foreign traces and resource reversal. Start with
  the causal resource-use effect, before any daughter or memory claim.
- Use authored cases to check observability, then register fresh development
  cases separately. Static throughput alone never licenses a repair endpoint.
