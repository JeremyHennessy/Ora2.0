## Required checks before a new panel

1. Derive a transition/prerequisite table from the contract separately from the
   producer. Exercise each missing and broken essential role, occupied slots,
   redundant constructors and material/energy shortages. Report refusal causes.
2. Audit raw-start formation separately from partial-damage maintenance.
3. Supply a fully accounted prepared positive witness that the **same endpoint
   evaluator used for worlds** accepts, and an impossible witness it refuses.
   Software fixtures are measurement checks, never accepted life evidence.
4. Check source accessibility and untouched ancestry at damage if the endpoint
   requires fresh first-use work. A positive count is not sufficient evidence.
5. Keep event validity, specification conformance and scientific decisions
   separate. A historical receipt interpreter may require its registered result;
   it must not be reused as a generic evaluator hardcoded to that result.

Run the bounded read-only diagnostic with
`python -B -m experiments.reachability_preflight`. It isolates guards using
prepared charge; that diagnostic charge is explicitly not a raw-accessible
experimental history. Regression checks are in `tests/test_reachability_preflight.py`.
