Original input is preserved. Canonical serialization removes Python aliases. The receipt binds input, binding and output hashes and a distinct proposed branch label.

Nine synthetic tests cover 1,728 role combinations plus collateral changes, aliasing, malformed context, branch collisions and forged authority. These are synthetic metadata checks, not paid source READs or organism trials. Exact raw-byte pins and limits are in `data/eka1-feedback-adapter-qualification-20261024.json`.

The input hash is a canonical JSON hash, not a claim about original checkpoint file bytes. The external READ-receipt hash is checked for format only; its contents, ancestry and authenticity are not established. Original event history must remain separately immutable.
