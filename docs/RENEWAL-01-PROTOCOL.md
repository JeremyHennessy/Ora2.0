## Definitions fixed before execution

An energy unit is capture-paid construction charge if its origin is activation or
recharge and both actual input-work parents have origin capture. No recursive
relabeling, initial endowment relabeling or removal of external ancestry. A chain
is clean when every immutable construction debit has that property. A free atom
can start a clean chain when its first held charge unit is capture-paid. An incoming
atom can extend a clean chain when it is free, has exactly3 charge units, and all3
are capture-paid. A release is clean if existing chain debits and the first3 pooled
residual units are capture-paid, length>=2, and pooled charge>=3. These are immediate
opportunities under current state, not assertions that a successful whole path
exists. Ghost clean release opportunity is recorded but has no functional endowment.
Already paid external debits cannot be erased by later charging; clean status is
construction ancestry, not retained object labels, reproduction or inheritance.
