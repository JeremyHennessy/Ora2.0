## What food-matched means

Match **exogenous source rules and initial budgets**, not realized meals:

- Same pinned source, packet/target rules, starting site and private state, 12 energy, 27 code words, 16 state units and 512 material units. Both policies pay actual reads, dispatches, nursery formation, division, overflow and deaths.
- Same physical initial stocks `[32,16,16,0]`, including site 0's 16 packets locked until global tick 64; four offers per site every 64 global dispatches and capacity 32. Unlocks are not additional stock. No free guaranteed arrivals or target/presence labels.
- Couple future paired Worlds by the same frozen source seed and exogenous rules. The **seed roster remains unassigned**. Admission/rejection, captures, birth scheduling, competition and early extinction are outcomes; different histories need not expose organisms to identical realized food or turns.
- Keep both fixed ports without selecting the matching one after seeing a target. Never stop a policy when it has eaten the same number of meals, restart an extinct World, discard a dead founder or choose only successful descendants.

Forcing identical captures would condition on an outcome of the strategy and would change the actual ecology. Offering equal inputs is a legitimate comparison; equal input is not a claim that every actor receives equal food. Global and individual time remain separate.

## Prospective lifetime question and controls

The intended unit is a **paired whole World/lineage**, with the existing 4,096-global-dispatch horizon and 256-own-turn expiry. A focal-only worksheet or frozen-child assay cannot silently replace whole-lineage competition and claim the same estimand.

The proposed primary is the number of founder offspring that themselves produce a paid child by the fixed horizon, per **all assigned initial founders**. This is finite-horizon reproductive expression, not universal viability. Keep actual births, deaths, expiries, late/censored followup, unfinished nurseries, intake, empty/incorrect attempts, rejected offers, heat, retained energy, material and dispatch costs as separate outcomes. A late child without a descendant by the cutoff counts zero for that finite-horizon primary; it is not called permanently sterile or dead. There is no posthoc weighted composite score.

The nursery-aware reference does not get an energy oracle. Its exact declared program is:

```text
0 CONST r1=1
1 FORAGE r0
2 XOR r0,r1
3 IF_NURSERY_INCOMPLETE ->6
4 DIVIDE
5 JUMP 1
6 COPY
7 JUMP 1

```

When the nursery is incomplete, the paid test routes to COPY; when complete, it routes to DIVIDE after another forage opportunity. The test itself costs a dispatch. Before fullness it replaces a refused division call, and it delays division to a later loop; it is not automatically cheaper or stronger. Nursery progress can indirectly reflect resource access, so disclose that operational channel. Blind means no explicit food-feedback/target access, not zero internal state.

A feedback-versus-different-blind-code result alone cannot establish that acquired information caused an advantage. A matched information-use lesion and paid sham remain required, with actual path costs and lethal side effects checked. Erasing/shuffling the source feedback would change the physics and needs separate review; this preparation grants no authority to do it. The current claim concerns a local port register, not an implemented older-site memory lookup or inheritance of an acquired answer.

The original Mobile54 scientific founder is preserved exactly. These authored references cannot be inserted into a scientific population or substituted for the founder under the guise of this preparation. Any proposed diagnostic that introduces an authored genotype needs its own independent admission and any required explicit operator authorization. ## Completed narrow mutation-path evidence review

The prospective preparation and fixed lookup scope were independently accepted before one bounded invocation. It examined **the same sixteen already-closed original Pressure71 mutating/parent-copy histories**. No new/reserved seed outcomes, mutation draws, interpreter calls or scientific populations were generated. All founders, paid births, dead actors and terminal/censored outcomes remain represented.

The [reader](../tools/eka0_closed_path_review.py) authenticates all raw bytes and tracks retained COPY, SELFWRITE and birth records rather than executing instructions. For each birth it checks all 27 paid write IDs, physical source units/values at COPY time and daughter values. It separately retains parent-birth genotype, the temporal copied-source vector and parent code at division. A vector collected across time need not have existed as one simultaneous genotype.

A strict intended-route edge requires unchanged parent code since its own birth, copied-source values equal that birth genotype, and a faithful transmission or exactly one additional fixed target edit. Any effective SELFWRITE excludes that parent from this strict predicate even if later reversed. A complete path must follow contiguous actual founder-to-child ancestry and end with the fixed target itself producing a paid child before any effective code change. This intentionally conservative predicate is not a claim about every possible evolutionary route.

There are 117 faithful transitions, 243 outside-subcube transition cases and four parent-code-changed cases. All 364 daughter records and 16 founder records include the source/context and terminal/followup fields. The four changed-parent division cases copied their original values before the effective changes, consistent with the earlier absence of copied acquired-word chains. Code at division alone would have misrepresented inheritance.

These findings do **not** mean that all 204 reproducing offspring were neutral intermediates, that mutation improves fitness, or that acquired knowledge was inherited. Shared historical resources and help can support reproduction. No strict intermediate beyond the founder was observed on this one human-targeted ten-edit route. That is a narrow evidence gap, not a global impossibility proof, an exhaustive genome search or permission to select a different genotype/bank.

The fixed target is an audit of one possibility witness, **not a prescribed genome that evolution must discover to count as success**. The viable-origin review gate must assess a credible route/mechanism under a separately reviewed scientific question; it must not turn the human-authored sequence into the evolutionary objective or require its prior observation before any possible capability-based experiment. No alternative candidate or experiment is admitted here.
