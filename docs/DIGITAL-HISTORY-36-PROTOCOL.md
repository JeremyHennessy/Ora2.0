## Two independent local interpretations

For each F read, toggle only its delivered bit and follow the recorded path until
the first changed ACT port or changed JZ successor. Stop at that first effect:
do not invent outcomes, later alternative trajectories, survival or resources.
Other F reads retain their actual delivered values until divergence. Identical
ACT ports retain their recorded outcomes. Retained-disabled controls reset
registers, memory and PC at each ACT exactly as recorded; unrelated delivered
values remain unrelated even when numerically equal to truthful feedback.

The forward implementation tracks XOR coefficients for each read through both
registers and all eight memory cells. CONST and later reads overwrite; XOR uses
symmetric difference, including exact self-cancellation. An ACT tests its used
register's low bit. JZ sensitivity requires an actual change of successor, not
merely a changed predicate when target equals fallthrough. Remove a read's
coefficients after its first effect. No dependence is propagated through a
divergent branch. The independent implementation uses one numerical toggled
local state per read and literal instruction replay, without producer imports.
Both must match every per-read result, not only totals.

Record first-effect kind/tick, whether ACT had a real opportunity, own versus
initial/empty/unrelated source, origin tick/truthful outcome/delivered value,
and whether read and effect occur strictly before task completion. Incomplete
histories use the recorded endpoint for diagnostic coverage only; they never
gain a completion bill. Reads without an effect remain explicit refusals to
show local use. Branch effects do not prove resource competence. Immediate
feedback reactions do not demonstrate retained-history learning. Even delayed
memory dependence does not demonstrate improvement, generalization or evolution.
The diagnosis authenticates local transitions against the already verified
full VM history; it does not replace the History35 full resource evaluator.
