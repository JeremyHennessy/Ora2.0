# Single-cell intervention envelope: offline custody component

**Implemented and tested on synthetic JSON only. No causal qualification or execution admission.** This extends the [source audit](EKA-1-CAUSAL-ASSAY-QUALIFICATION-20261023.md) without changing an experiment, organism, restore method or live assistant.

`tools/eka1_intervention_envelope.py` compares supplied before/after JSON structures. It accepts exactly one declared private memory-cell replacement for a proposed single-cell lesion. Intact and sham preserve the original value. It rejects all other differences, including control phase, resources, registers, code, nursery, other actors, food, time and unauthorized receipt fields. Canonical hashes also reject boolean/integer substitutions that Python equality alone could accept. Inputs remain untouched. This is a narrow structural check, not a complete World schema validator.

The returned record always says history authentication, pricing, nonlethality, causal qualification and execution authority are false. There is no loader, replay, mutation method or launcher. A syntactically valid envelope cannot establish authentic ancestry. No local or external model is called.

Seven tests passed, including 128 address/value combinations and adversarial collateral, sham, type and extra-field changes. Independent review found that shared Python lists could hide a second-actor mutation under deepcopy. The corrected checker breaks aliases through a JSON round trip; a regression test rejects that collateral change. Original six-test evidence is retained separately. Fixtures intentionally omit required World state and are not organism histories. Neither a VM nor a scientific population was run. These tests demonstrate software rejection rules, not that a memory cell carries useful information or that changing it is harmless.

## The remaining causal boundary

The single-cell channel is a candidate measurement scope, not an assumption that all learning uses these cells. No cell, replacement value or checkpoint may be picked after observing a favourable learning score. A zero replacement is not intrinsically neutral. Registers, feedback, code, phase, position and messages remain potential information channels outside this envelope.

Before diagnostic execution, independently register a delayed-use exposure/probe boundary based on personally available observations, the cell/value-selection rule, handling costs and control fixtures. During-probe feedback can support immediate reacquisition or reflexes; its treatment must be specified explicitly, without supplying target labels. Delayed use is this assay's intended claim, not a universal definition of learning.

Intact, sham and lesion must start from one authenticated actual checkpoint. Equal handling costs and allowed receipt differences must be declared. Preserving other fields at the intervention instant does **not** prove downstream phase, survival or reproduction remains unaffected. Delayed-use positive fixtures and blind, reactive, phase and reproduction negatives must qualify sensitivity and specificity under a separately admitted bounded software protocol. No useful-origin, sample size, effect margin or arbitrary intervention price is supplied here.

The existing exact-replay restoration guard remains intact. Future integration must first authenticate the original history, then separately authorize a precisely priced delta and bind original/derived custody receipts. This offline checker supplies only one comparison component of that future mechanism. It cannot bypass replay equality or authorize altered history.

**Next highest-value requirement:** freeze a minimal synthetic delayed-use/phase-negative protocol and the intervention pricing/custody contract for independent review before any VM execution. If selective nonlethality cannot be established, retain NO-GO rather than interpret state damage as loss of learning.

Resource affordability, mutation opportunity, sampling, reserved conditions, native custody and scientific admission remain held. All prior results remain preserved. No stage of organism learning or evolution advances on these software checks.
