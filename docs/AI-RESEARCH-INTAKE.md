# AI-Research intake receipts for independent Ora2.0 experiments

**Purpose:** consume new scientific evidence from the separately maintained [AI-Research library](https://github.com/JeremyHennessy/AI-Research), without copying its model plans wholesale or allowing it to mutate the experiment's frozen protocol.

## Intake boundaries

- Only **artificial-life scientific publications, evidence caveats and experimental methods** inform Ora2.0. No material from the old Ora/AgentTest project is a design input.
- Distinguish screened abstracts/metadata (E1), full methodology review (E2), and locally reproduced measured outcomes (E3). An AI-Research E2 review is **not** an Ora2.0 experimental replication.
- Before any new study, check the research repository's SHA, newest ALife dossiers, corrections and CI; log accepted/contradictory findings here.
- Once a trial protocol is locked to a Git commit, **new literature cannot silently alter its sampled parameters, outcomes or eligibility rules**. Material changes require a new preregistered experiment ID.
- Do not automatically import publication code, papers, credentials, private files, external services or new code into a running organism.
- No live automatic background crawler or cross-repository sync is configured here. Review occurs at research-design checkpoints.
