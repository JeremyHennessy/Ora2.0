## Candidate and falsifiable question

Can a finite resource-paid chain be constructed without a supplied working
template, then perform the existing installed capture reaction? Which new
possibilities are necessary? This distinct toy candidate changes three things:
actor-free nonspecific association, partial recharge of a ready/assembly atom,
and payment of release from local precursor potential rather than a parent account.
Test each removal independently; do not silently extend ENERGY-02 or REACTIVATE-01.
This is a conditional physical-possibility test. Ordered encounters, target length,
stable activation and installed reaction capabilities are explicit scaffolding.

Lengths2,3,4 and all28 binary input words; no word selected for success. Each case
contains n inert all-zero reserve atoms, n-1 inert bond-energy reserve, two phases
of n raw precursor atoms bearing the same registered word, and complete finite
food/work stocks at genesis. Template mode alone wires the reserve atoms into a
supplied all-zero C template, with zero private work; other arms leave them inert.
Same atom/bit counts and energy across paired arms. Reserve bonds cannot fund work.
Repeating input words/ordering in phase2 is supplied information, not inheritance.

Each phase has n activation foods Ai, one top-up food Q,2n+2 maintenance foods Fi
and one probe P:3n+4 food atoms, all with potential8 and a separately crossed
bit0/1. Food composition is not chosen after seeing a product. Each phase has
b finite externally supplied work units, b in {0,2n,2n+2}; capacity is never borrowed.
For withdrawn second phases, that phase's external bank stays sealed, still counted
in the ledger. Food-withdrawal keeps all second-phase foods sealed, also counted.
All sources, current owners and waste remain explicit. No additions after genesis.

External activation pays2 bank work plus one food8. A raw atom with zero local
potential receives3 new source-linked units, heat7. Partial top-up pays the same
2 work and food8, stores exactly the empty capacity up to3 (here1 after recognition),
and dissipates the remainder: heat10 minus newly stored units. Producer activation
instead pays from an actual object's work and requires its length>=2 and terminal
bit complementary to the food. Zero-full-space activation and unfunded attempts
cost0 and leave all resources unchanged. Existing old law lacks partial top-up.

Recognize pays1 incoming-atom potential to heat. Generic modes accept either bit;
template mode requires a present C/D0 and the bit at the next channel position.
Mismatches still pay1 but leave the atom ready. Association-off pays the same
recognition work but cannot bind. First binding needs no bond; each later binding
pays2 incoming-atom potential, storing1 uniquely identified bond and heat1.
No cross-precursor pooling funds recognition/ligation. Complete channels alone
can release: consume1 pooled residual local unit as heat and transfer2 units into
a newly identified object. Full formation/release/endowment debit stays3n+1:
n recognition +2(n-1) ligation +1 release +2 endowment. Ghost uses the identical
debit/structure but dissipates endowment2, so it is an energetic inert control.
Parent-release mode instead requires actual parent work1 and local endowment2.
Its founder-free first release cannot be paid; no environment fallback is allowed.

Capture/probe uses the existing toy accounting: length>=2, complementary food and
actual object work2; food becomes waste,3 new work units and heat7, with overflow
above length capacity dissipated. This ability is installed, not discovered.
No waste-to-food regeneration exists. Recharge is paid replenishment of local
potential using a fresh finite food; it neither recycles waste nor creates energy.

## Fixed panel and event order

Cross28 words,6 modes {generic,template,ghost,association_off,topup_off,parent_release},
3 external budgets,2 food bits,3 renewal settings {external,withdrawn,food_withdrawn}:
3,024 authored cases. Phase0 activation always uses the finite environment account.
Phase1 external setting keeps that finite subsidy; withdrawn uses only D0 work;
food_withdrawn additionally seals its foods. No successful-case filtering.

For each phase and slot i: parent requests harvest Fi*2 and Fi*2+1, activation Ai,
recognition Mi, binding. Immediately after the first binding opportunity request
two extra maintenance captures F2n,F2n+1 and partial top-up of M0 using Q.
Then request release Dp and its probe P. Parent is C in phase0 (absent except
template mode), D0 in phase1. The complete schedule runs even after failure.
Per phase5n+5 events, total133,920 events. Retain every unavailable, mismatched,
starved, depleted and inert outcome. Any surprising negative is a result, not
permission to adjust stocks, prices, order or horizon.

## Independent accounting, decisions and limits

Every event must preserve all immutable atom identities, bit composition and unique
ownership across reserve, ready, pending/channel, bodies, food and waste. Count all
live work, activation and bonds once, plus inert supplied bond reserve, unused
food8 and heat, against genesis total. Preserve unit origins, food sources, spent
parent work, object parents, component IDs, paid construction histories and complete
failed channels. Metadata ancestry is informational, never a second energy owner.
Classify second construction as captured-resource-funded only when each construction
activation unit came from D0 and all its input work originated in D0 captures;
genesis/environment work cannot be relabeled as producer resource capture.

Implement a separate interpreter/auditor importing no assay worker. Independently
enumerate the full panel and schedule, derive genesis, replay every event, verify
mass/energy/provenance, source hashes, terminal histories and aggregate counts.
Require read-only audits and byte-identical raw/summary/audit replay in a fresh
directory. Test negative controls, exact3n+1 price, capacity/zero-input failure,
ghost cost matching, ancestor/source forgeries and coherent hash forgeries.

A feasibility-positive result requires at least one founder-free generic released
object with an executed paid probe, zero conservation errors, independent audit,
and no productive ghost/association-off/top-up-off/parent-release first endpoint.
Report every budget/length/food/renewal outcome and captured-resource-paid second
construction separately. Template selectivity is not evidence of natural emergence.
If no funded generic path exists, close this candidate negative; do not tune it.
Any ledger/source/replay discrepancy falsifies implementation acceptance and must
be diagnosed/preserved before fixes. Preserve the original existing-law negative
receipt and relevant unchanged-source regressions as explicit baselines.
