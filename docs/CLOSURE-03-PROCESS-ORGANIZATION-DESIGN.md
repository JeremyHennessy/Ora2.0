# CLOSURE-03 — Competing process-organization hypothesis (not implemented)

**2026-10-08. Status: independent scientific design only.** There is **no operating CLOSURE-03 world**, no living organism, and no self-modifying host code. This is an original project proposal, not a claim of scientific priority.

## Why change directions?

The cost-controlled [CLOSURE-02](CLOSURE-02-RESULTS.md) results showed that an authored M shell can suppress particle movement and modestly increase A/R recovery versus an inert shell, but **continued M synthesis does not improve recovery over cost-matched W production**, while disabling shell synthesis entirely yields far greater recovery. Under this finite artificial chemistry, making the shell is **too costly to justify as the central maintenance pathway**.

The immediate reaction should **not** be to adjust the membrane rate until a high score appears. Preserve the old world as a falsified/baseline experiment. Test a genuinely different source of organization.

## New scientific question

Can a bounded, non-neural collection of local computational **processes** restore the processes that generate its *own ability to restore itself*, while paying resource, memory and execution costs, without the engine granting an object's identity, a permanent repair API, or extra survival reward?

**We should expect ordinary fault-tolerant computation to sometimes show this behavior.** The objective is to distinguish *causal self-maintenance* from a preinstalled replacement scheduler or a passive attractor, not assume the phenomenon is alive.

## Two rival hypotheses, both open

- **P-H1, internally dependent restoration:** Randomly sampled local process-rule interactions sometimes form a closed productive dependency set that maintains a core under perturbation and reconstructs failed repair rules by consuming bounded resources. Removing an internal dependency cut set decreases recovery more than a matched nonproductive-edge deletion.
- **P-H0, simulator shortcut:** All observed recovery is reducible to hardcoded graph connectivity, a hidden copying primitive, externally refreshed instruction budget, capped memory protection or a passive recurrent attractor. A control matched for topology, resource and computation shows the same result.

Even a positive P-H1 would demonstrate at most **interesting bounded computational feedback**, not self-produced individuality, heredity, intelligence or life.

## Candidate substrate (NOT parameters or architecture commitment)

Local **material tokens** represent active process rules and potential links, but are not predeclared living entities. Fixed interpreter primitives can transform resource token + active rule inputs into additional process tokens; rules themselves decay or are disabled by the environment; all writes consume explicit token/material and CPU fuel. No host file I/O, GitHub operations, dynamically imported Python or network instruction is exposed.

Sample many independent *candidate rule universes*, including sterile and purely cyclic-but-unproductive universes, from a frozen distribution without selecting successful ones. Detect functional clusters *after* generating worlds with preregistered causal criteria; don't hardcode one privileged “organism” cluster.

## Decisive predeclared controls required before any run

1. **Repair-of-repair:** damage both active productive node(s) and node(s) that make their replacements; require reconstruction of the replacement process through the remaining internal causal network.
2. **Passive attractor:** identical memory/budget/transition cadence but no productive token synthesis.
3. **Externally rescued control:** exact same materials but engine reintroduces missing processes, clearly labeled as **external** and never counted as endogenous.
4. **Randomized cut/sham:** blind graph-based knockout of productive repair links versus matched edge count, catalyst degree and execution opportunity. Include insufficient-degree worlds in denominators.
5. **Resource and compute normalization:** same initial token/fuel budget and actual work receipt per node; no immortality by doing less work, no externally awarded novelty reward.
6. **Multiple interpretations of identity:** test process-dependency components, spatial proximity and observer-defined boundaries separately; an inert cycle should not pass simply by persistence.
7. **Fresh hidden perturbations:** hold out resource gaps, multi-point damage and new topology, with separate development seeds and no post-hoc threshold adjustment.

## What to measure

Separate endpoints rather than one aliveness score: regenerated internal prerequisite count; independent replacement origin; fraction of failed worlds; material/fuel cost per viable recovery; causal knockout difference; robustness of region/identity detectors against nulls; error-free event provenance; resource accounting and exact reproducibility. Later, independently test **heredity** and **new ecological function** if any meaningful organization emerges.
