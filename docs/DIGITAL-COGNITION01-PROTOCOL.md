# DIGITAL-COGNITION01 — capability-first, paid within-life learning feasibility

Pre-registered October 14, 2026, before executing primary and unseen cohorts. This is an **isolated new cognitive world** and not Exposure23 / Pressure71, not a repair of past negative experiments or a new persistent Ora. ## Frozen environmental law
- Eight sites numbered 0..7. At tick t (0..255), site = t % 8 is observable, but target/seed/tick/phase are not policy inputs. For ticks 0..127, rewarding target = int(SHA256(JSON canonical ["COGNITION01-target",seed,site]) first 16 hexadecimal digits,16)%2. At ticks 128..255 that target is inverted. Programmer-supplied site schedule and reversal are disclosed.
- Exactly 256 tick opportunities in **every** arm, retaining all no-action/death slots. One original actor starts at energy 64, cap 64, and eight zero signed context weights. Every tick offers one exogenous energy packet of 12. All actual attempts cost 3 energy for sense, action and possible memory operation even in the disabled/fixed controls. Matching the binary target collects up to 12 subject to cap; unused and failed packets dissipate as heat. When energy is below 3, the actor dies (remainder becomes heat), no further attempts occur, and all later null opportunities remain in the denominator. No free retries, rescues, extra food, edited prior cohorts or survivor-only comparisons.
- Intact cognition uses eight weights clipped to [-12,12], updating its **actually observed site** AFTER feedback by learning rate 2: successful port 1 => +2, failed port 1 => -2, successful port 0 => -2, failed port 0 => +2. Choose port 1 for positive, port 0 for negative, tie by deterministic SHA256 of ["COGNITION01-tie",seed,tick]. On SHA256(["COGNITION01-explore",seed,tick]) first 16 hex digits %16 == 0, all arms instead use SHA256(["COGNITION01-noise",seed,tick]) first 16 hex digits %2. No hidden target reaches any policy. The generic update machinery is supplied by researchers, not learned or evolved.
- Exact seven arms, same seed/site/packet/exploration/energy budget: (1) intact own-site weight, (2) memory_disabled zero weights, (3) misbound_history paid updates written to (site+1)%8 instead of the actual site, (4) latest_reactive repeats immediately preceding chosen port if successful, flips if failed, retains no site evidence, (5) fixed site-specific port from SHA256(["COGNITION01-fixed",seed,site]) %2, and (6/7) constant0/constant1. Any writes not affecting action are still charged. No hindsight teacher or extra sensory signal.
- Record full actual actions, feedback, memory before/after, resources, energy/heat, packet identity, death and world-state provenance. Recorded target is forensic data only, never policy input. Require independently replayed row-level semantics and conservation: initial64 + 12*ticks = actor_energy + heat.
