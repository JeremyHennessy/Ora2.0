## C. One decision-changing learning proposal: evidence-owned return, not a programmed winner

**Research question:** In the *existing* fully paid digital VM, is there an attainable same-organism resource encounter where an **older truthful observation** changes a later action's earned useful resource compared with a feasible **latest-reactive** and fixed explorer, after paying for the complete additional sensing, memory, travel and action costs?

Do **not** begin by inserting AgentTest's two-clock model, its inquiry policy, a selected successful genotype, a curiosity reward, or a new world law. First ask whether the present law offers the necessary *information difference and budget*.

### Gate 0 — Prove informative, affordable opportunity (read-only first)

- Reconstruct an actual or prospectively derivable **same actor** sequence: observe a nonempty resource outcome at site A → act or move at B while the immediate feedback changes → revisit A or a related site with new, finite resource opportunity. A release clock alone is not experience.
- Identify two lawful histories with **the same decision-time public/current information** (including cue, position, latest feedback and relevant affordable state) but different **older personally observed evidence**, making different actions beneficial *under the existing physical/data law*. Show the exact target and available resources independently in the audit, never as privileged organism input.
- Compare with a real **latest-reactive** policy that uses current public information, a paid fixed exploratory policy and, when appropriate, a simpler stationary strategy. If the current public state already contains all useful information, older-memory use has **no added informational target** in that context.
- Verify cold survival in both resource orientations; natural/paid access to the informative encounters; enough remaining food, memory slots, executable instructions and energy for a later decision. Include empty/failed probes, cap losses, movement and life expiry. The earlier History44 program family cannot silently acquire MOVE/SENSE operations it lacks.
- If there is no paired difference or affordable completed action, **STOP before a new primary cohort**. Report information sufficiency, missing opportunity or unaffordable cost specifically. Do not rerun old frozen samples or adjust prices/horizons to manufacture a favorable case.

### Gate 1 — Audit the full causal ladder before claiming learning

For each candidate actor, keep separate authenticated fields for:

1. **Experience actually earned:** time, entity, actual nonempty attempt and environmental outcome (not the experimenter's target).
2. **Durable evidence retained:** causal earlier-event ancestry across every used register, RAM cell, latch, PC, code, message or other channel, plus exact storage/read/update costs.
3. **Decision made later:** pre-action declared candidate choice and prediction, plus an appropriate fixed/latest-reactive comparison frozen without seeing its outcome.
4. **Consequences actually earned:** action, own-food acquisition, net paid resources, survival, deaths, unsuccessful attempts and actual opportunity.
5. **Causal attribution:** memory-disabled and own-history association-disrupted alternatives on the same exogenous opportunities, plus an order-only diagnostic where useful; actual outcomes remain each arm's own earned outcomes.
6. **Unseen generalization:** complete predeclared primary and untouched holdout contexts, including no-change, genuine changed-context and sparse misleading-observation controls *only if the existing law supports them*.

No bonus for memorizing, asking questions, changing a prediction, making a novel choice, or increasing a prediction accuracy score by itself. A positive result requires **useful own-action advantage after all costs** and a causal loss of that advantage when the specific earlier-own-experience information is removed, against viable baselines. All founders, dead actors, null actions, and failed opportunity gates remain in the denominator.

### Gate 2 — A genuinely informative next experiment, only if Gate 0 passes

Register prospectively one small bounded **same-substrate, own-history causal test**, independently interpreted, with source-neutral/performance-blind candidate selection. Compare actual resource/survival benefit of earlier-history access versus latest-reactive, fixed, memory-disabled and actual-channel-disrupted alternatives under identical exogenous resource opportunities; reserve independent unseen contexts. Do not reuse a historical source program merely because its prior outcome looks favorable.

An *authored nonlearning explorer* may be disclosed as ordinary starting infrastructure, without counting its exploration as discovered; a supplied adaptive software witness may test instrumentation but is **not** eligible as an emerged learner. Reproduction is **not** a universal prerequisite for this test. Do not equate physical host checkpoint restart with organism memory use.

### Optional, after any real Gate 1 positive: changed-context memory comparison

AgentTest's two-clock controlled reversal suggests a narrow future hypothesis: recent, verified contradictory experience can improve later choice in a changed local context while retaining long-term history. Run this only if the present VM exposes a real paid, decision-relevant change and meaningful no-change/noise alternatives. Compare with strong history-inclusive and latest-reactive controls on **earned utility**, not just prediction. Do not import the AgentTest engineering threshold, reference classes or source histories. This is **not** a prerequisite for first useful within-life learning.

## D. Separate lessons for evolution and persistent worlds

- **Inheritance:** AgentTest's learned-prediction mechanisms are not heritable programming. Ora Functional69 must continue separating copied code value from birth position, startup resources, parent schedule and shared ecology. Keep neutral ancestry, valid NULL children and every death; a naturally observed advantage is not a causal inherited improvement until a fair control establishes it.
- **Novelty:** The object-world experiments suggest generic interactions plus hidden consequences can provide interesting opportunities without a fixed reward/solution. In Ora, first document a **demonstrated missing reachable affordance** before changing the instruction set or ecological law. Do not put a scripted survival/learning strategy in the environment.
- **Persistence:** AgentTest's lossless full-history and read-only future shadow are useful engineering patterns, but Ora already has [Capsule01](DIGITAL-CAPSULE01-DATA-RECEIPT.md) normal-stop save/load progress. Crash loss policy, off-host recovery and production isolation remain separate. No new observer/heartbeat/service activation follows from these comparisons.
- **Measurements:** Every comparison must distinguish pre-action prediction, observed effect, personal-history-caused *choice*, and actual useful resource/survival effect. Also report strong comparator performance and null cases; software test pass, CI pass and a live process are not evidence of intelligence, evolution, open-ended life or consciousness.

## E. Implementation priority and ownership

**Suggested decision for the Ora2.0 development owner:** Continue the already frozen Functional69 scientific qualification as planned; **in parallel**, make the next Stage 6 research work a small read-only existing-law information/opportunity/budget check specified in Gate 0. If it passes, prospectively design the one cheapest causal organism-level test under Gate 1 and Gate 2. If it fails, report the exact missing information/opportunity/cost term and only then consider whether a distinct new substrate is justified. Avoid another broad random source survey or generic wrapper rewrite.
