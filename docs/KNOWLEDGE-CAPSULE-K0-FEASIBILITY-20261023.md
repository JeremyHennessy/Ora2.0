## Proposed cheap interface and explicit unknown costs

A future K1 could validate a tiny fixed offline snapshot using existing host storage. A future K2 might offer a two-byte query and five-byte response: one byte availability, one byte relation, one byte value and a two-byte source ID. The fields carry at most33 semantic bits in40 wire bits. A16-entry selection needs four logical bits, but the proposed wire request still costs16bits. NULL is explicit; there is no privileged fallback.

## Staged acceptance, controls and stopping rules

1. **K1 software:** fixed tiny offline catalog; exact hashes, rights/scope and corrupt/missing/stale/conflicting/adversarial-entry refusals. Reuse storage; no persistent ingestion service. Stop on ambiguous rights/authority. Software tests give zero organism-learning credit.
2. **K2 paid read:** prospectively freeze task, channel, source/encoding, costs, samples and authority. Compare no-library, irrelevant/wrong entries, fixed/reactive and equal-access/equal-budget policies, and personal-memory-disabled/shuffled-history controls. Match memory/context capacity; include every failed/NULL/dead opportunity. An oracle is only an upper bound. Stop before Worlds if current cues already reveal the answer, hints leak evaluator truth, or the whole information path is unaffordable.
3. **K3 knowledge seeking:** reserved unseen tasks and changed/unavailable/misleading information must improve actual decisions/returns due to experience beyond equally funded fixed policies. A supplied lookup is not learned information seeking.
4. **K4 culture:** attributed organism-to-organism teaching; no-teaching/shuffled/personal-learning controls and full communication costs. Demonstrate receiver benefit before claiming accumulating culture.
5. **K5 inherited capacity:** independently viable descendants, explicit variation and differential success under unchanged laws. Cultural transmission and copied source are distinct mechanisms.

**Stop here.** K0 is a traceability and feasibility draft. No K1 service or primary science is authorized. The next major engineering goal remains a supervised world preserving the same population across interruptions.
